AND:

Both conditions required. (TRUE only if both inputs are TRUE.)

TRUE (1) + TRUE (1) = TRUE (1) TRUE (1) + FALSE (0) = FALSE (0) FALSE (0) + FALSE (0) = FALSE (0)
OR:

Either condition required. (TRUE if either input is TRUE.)

TRUE (1) + FALSE (0) = TRUE (1) TRUE (1) + TRUE (1) = TRUE (1) FALSE (0) + FALSE (0) = FALSE (0)
NOT:

Reverse condition. (Reverses 1 to 0, and 0 to 1.)

NOT TRUE (1) = FALSE (0) NOT FALSE (0) = TRUE (1)
XOR: (Exclusive OR)

Exactly one condition required. (TRUE only if inputs differ.)

TRUE (1) + FALSE (0) = TRUE (1) TRUE (1) + TRUE (1) = FALSE (0) FALSE (0) + FALSE (0) = FALSE (0)
NAND: (Opposite of AND)

Anything except both. (TRUE unless both inputs are TRUE.)

TRUE (1) + FALSE (0) = TRUE (1) FALSE (0) + FALSE (0) = TRUE (1) TRUE (1) + TRUE (1) = FALSE (0)
